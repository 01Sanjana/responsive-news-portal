# News Today - Responsive News Portal

A modern and responsive digital news portal homepage built using **HTML5 and CSS3**. The website is designed to provide a newspaper-style experience across desktop, tablet, and mobile devices.

##  Features

- 📰 Modern news portal homepage
- 🚨 Breaking news section
- ⭐ Featured news article
- 🕒 Latest news updates
- 🎥 Embedded YouTube news video
- 🗞️ Technology, Sports, Business and India news cards
- 📱 Fully responsive layout
- ✨ Hover effects and smooth transitions
- 📐 Responsive navigation bar
- 🎨 Clean and modern UI

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Media Queries
- z-index
- CSS Transitions
- YouTube iframe
